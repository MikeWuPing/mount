# mount v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `mount.efi`, a UEFI Shell CLI tool: `mount -<FORMAT>` loads efifs drivers and rescans volumes; `mount -ISO <file>` presents an ISO file as a virtual block device (loop) that the firmware driver stack mounts.

**Architecture:** Single `UEFI_APPLICATION` (spec §4). Three modules: `FsDriver.c` (driver load + ConnectController rescan), `LoopDisk.c` (fake `EFI_BLOCK_IO_PROTOCOL` backed by a file), `MapReport.c` (map refresh + new-volume diff report). efifs drivers are prebuilt `.efi` files from efi.akeo.ie deployed beside mount.efi in `drivers/`. All validation via QEMU closed loop (serial version assert + startup.nsh scenarios + QMP screendump).

**Tech Stack:** edk2 (VS2019, X64, DEBUG), UefiShellLib, QEMU 10.2.50-dev + OVMF (`D:\Work\Code\ContraQwen\OVMF_CODE.fd`), PowerShell build/run scripts, Python (mkfatimg.py, qmp_drive.py).

**Spec:** `docs/superpowers/specs/2026-08-20-mount-design.md`. v1 scope = Phase 0~3.

## Global Constraints

- ALL user-visible strings (help/prompts/reports/errors) in ENGLISH (req.md #9). Console font has no CJK glyphs. Serial DEBUG logs also English.
- Help output contains the literal line `Author: Mike Wu` (req.md #8).
- Marker/test files inside images use ASCII names (same font limitation applies to `dir` output).
- Environment is pre-installed; NEVER download edk2/QEMU/toolchains. Downloading driver binaries from efi.akeo.ie IS in scope.
- edk2 tree (`D:\Work\Code\edk2`) is NEVER modified. MountPkg lives in `D:\Work\Code\mount`, built with `PACKAGES_PATH=D:\Work\Code\mount`.
- Version discipline: every build via `tools/Build-Mount.ps1` only (BUILD+1, regen `Version.h`, write `expected_version.txt`). Never run a stale `.efi`. Success criterion of every QEMU run: serial `APP_VERSION=` matches `expected_version.txt` (except `-NoVersionCheck` runs in Phase 0 where mount.efi does not exist yet).
- PowerShell 5.1 reads BOM-less .ps1 as ANSI/GBK: keep ALL comments in .ps1 files pure ASCII.
- This machine sets `NoDefaultCurrentDirectoryInExePath=1`: build command must use `.\edksetup.bat` (leading `.\`).
- QEMU gotchas (gufile-proven): no `-machine q35` with this OVMF; every disk uses `cache=directsync`; readonly images go through virtio-blk (ide-hd rejects readonly); FAT images are partitionless superfloppy built by `tools/mkfatimg.py`.
- Commit after every task (git repo root `D:\Work\Code\mount`).
- Serial log channel: DSC maps `DebugLib|BaseDebugLibSerialPort` + `SerialIoLib` (16550 COM1 0x3F8) + custom `FixedDebugPrintErrorLevelLib` + `PcdDebugPropertyMask|0x03` + `PcdFixedDebugPrintErrorLevel|0xFFFFFFFF`. Use `DEBUG((DEBUG_INFO, ...))` (mask includes INFO).

- [ ] **Step 2: Write `tools/Run-MountQemu.ps1`**

```powershell
param(
  [string]$ProjectRoot = 'D:\Work\Code\mount',
  [string]$OvmfCode = 'D:\Work\Code\ContraQwen\OVMF_CODE.fd',
  [int]$QmpPort = 4556,
  [string]$Script = '',
  [int]$MaxShots = 40,
  [string]$DiskImage = 'D:\Work\Code\mount\qemu_disk.img',
  [string]$SecondImage = '',
  [switch]$SecondImageReadOnly,
  [switch]$NoVersionCheck
)
# NOTE: keep comments pure ASCII. PowerShell 5.1 reads BOM-less .ps1 as
# ANSI (GBK); a UTF-8 comment ending in a GBK lead byte swallows the
# next source line.
$ErrorActionPreference = 'Stop'
$qemu = 'C:\Program Files\qemu\qemu-system-x86_64.exe'
$runLogs = Join-Path $ProjectRoot 'run_logs'
$snapshot = Join-Path $ProjectRoot 'snapshot'
New-Item -ItemType Directory -Force -Path $runLogs, $snapshot | Out-Null
$stamp = Get-Date -Format 'yyyyMMdd_HHmmss'
$serial = Join-Path $runLogs ($stamp + '_serial.log')
$stderrLog = Join-Path $runLogs ($stamp + '_stderr.log')
# Fresh copy of the disk image per run: guest writes land on the temp
# copy, the source image stays clean. Temp image kept for inspection.
$tempImage = Join-Path $env:TEMP ("mount_disk_$stamp.img")
Copy-Item $DiskImage $tempImage -Force
# cache=directsync (gufile-proven): default/writethrough cache makes
# QEMU-for-Windows exit silently mid-run (Windows file-cache issue).
$driveArgs = "-drive format=raw,file=`"$tempImage`",cache=directsync"
$tempImage2 = ''
if ($SecondImage) {
  $tempImage2 = Join-Path $env:TEMP ("mount_disk2_$stamp.img")
  Copy-Item $SecondImage $tempImage2 -Force
  if ($SecondImageReadOnly) {
    # QEMU refuses readonly nodes on ide-hd; route readonly images
    # through virtio-blk-pci (OVMF has VirtioBlkDxe).
    $driveArgs += " -drive if=none,format=raw,file=`"$tempImage2`",cache=directsync,readonly=on,id=mount2 -device virtio-blk-pci,drive=mount2"
  } else {
    $driveArgs += " -drive format=raw,file=`"$tempImage2`",cache=directsync"
  }
}
# Proven OVMF launch: no -machine q35, no vars pflash (falls back to the
# internal UEFI Shell which runs startup.nsh from fs0:), -net none.
$args = "-m 256M -vga std -net none -display none -serial file:`"$serial`" " +
  "-qmp tcp:127.0.0.1:$QmpPort,server,nowait " +
  "-drive if=pflash,format=raw,readonly=on,file=`"$OvmfCode`" " + $driveArgs
$proc = Start-Process -FilePath $qemu -ArgumentList $args -PassThru `
  -RedirectStandardError $stderrLog -RedirectStandardOutput (Join-Path $runLogs ($stamp + '_stdout.log'))
$py = Join-Path $ProjectRoot 'tools\qmp_drive.py'
python $py --port $QmpPort --shot-dir $snapshot --qemu-pid $proc.Id --max-shots $MaxShots --script $Script
if (-not $proc.HasExited) { $proc.Kill(); $proc.WaitForExit() }
$err = if (Test-Path $stderrLog) { Get-Content -Raw $stderrLog } else { '' }
if ($err -match 'assertion|Assertion failed|ERROR:') {
  Write-Host 'QEMU STDERR:'; Write-Host $err
  throw "QEMU reported failures (see $stderrLog)"
}
if (!$NoVersionCheck) {
  & (Join-Path $ProjectRoot 'tools\Test-AppVersion.ps1') `
    -ExpectedVersionFile (Join-Path $ProjectRoot 'qemu_disk\expected_version.txt') -SerialLog $serial -SnapshotDir $snapshot
}
Write-Host "SERIAL: $serial"
Write-Host "STDERR: $stderrLog"
Write-Host "DISK: $tempImage (kept for inspection)"
if ($tempImage2) { Write-Host "DISK2: $tempImage2 (kept for inspection)" }
```

Note the QMP port default 4556 (gufile uses 4555; different port avoids collision if both projects run).

- [ ] **Step 1: Write `test_images/New-TestIso.ps1`** (IMAPI2FS, no external downloads)

```powershell
# Create small test ISOs: pure ISO9660 and pure UDF, with ASCII marker
# files (UEFI Shell console has no CJK glyphs).
# Usage: powershell -ExecutionPolicy Bypass -File New-TestIso.ps1
# NOTE: comments pure ASCII (PS 5.1 BOM-less .ps1 is read as ANSI/GBK).
$ErrorActionPreference = 'Stop'
Set-Location -PSScriptRoot 2>$null; Set-Location $PSScriptRoot
$work = Join-Path $PWD 'iso_stage'
if (Test-Path $work) { Remove-Item $work -Recurse -Force }
New-Item -ItemType Directory -Force -Path "$work\sub" | Out-Null
Set-Content -Path "$work\marker.txt" -Value 'ISO-MOUNT-OK'
Set-Content -Path "$work\sub\inner.txt" -Value 'nested content'

# FsiFileSystems: ISO9660=1, Joliet=2, UDF=4
function New-Iso([int]$FsFlag, [string]$Label, [string]$Out) {
  $fsi = New-Object -ComObject IMAPI2FS.MsftFileSystemImage
  $fsi.VolumeName = $Label
  $fsi.FileSystemsToCreate = $FsFlag
  $fsi.Root.AddTree((Join-Path $PWD 'iso_stage'), $false)
  $result = $fsi.CreateResultImage()
  # Save the IStream to a file via ADODB.Stream
  $stream = $result.Image.Stream
  $ado = New-Object -ComObject ADODB.Stream
  $ado.Type = 1  # binary
  $ado.Open()
  $ado.Write($stream)
  $ado.SaveToFile($Out, 2)  # overwrite
  $ado.Close()
  Write-Host "created $Out ($((Get-Item $Out).Length) bytes)"
}
New-Iso 1 'ISO9660TEST' (Join-Path $PWD 'iso9660_test.iso')
New-Iso 4 'UDFTEST'     (Join-Path $PWD 'udf_test.iso')
Remove-Item $work -Recurse -Force
```

If `$ado.Write($stream)` fails to bind the IStream directly (COM marshalling), replace with the .NET approach: read the stream into a byte[] via a `System.Runtime.InteropServices.ComTypes.IStream` wrapper (`IStream.CopyTo` into a `Marshal.AllocHGlobal` buffer), then `[System.IO.File]::WriteAllBytes`. Keep that fallback code in the script as a `try/catch`.

CONST MOUNT_FORMAT_ENTRY *

  IN CONST CHAR16  *Name
  )
{
  UINTN  Index;

      return &mFormats[Index];

  // StrCmp is case-sensitive; options arrive uppercase from users too.
  // Fall back to case-insensitive scan.
  for (Index = 0; Index < MOUNT_FORMAT_COUNT; Index++) {

      return &mFormats[Index];
    }
  }
  return NULL;

  VOID
  )

#include "MapReport.h"

#define MOUNT_MAX_PATH  256

// Resolve mount.efi's own directory: volume handle + dir-without-filename.
STATIC
EFI_STATUS
MountGetSelfDir (
  OUT EFI_HANDLE  *VolHandle,
  OUT CHAR16      *DirPath   // size MOUNT_MAX_PATH; L"" when at volume root
  )
{
  EFI_STATUS                 Status;
  EFI_LOADED_IMAGE_PROTOCOL  *LoadedImage;
  EFI_DEVICE_PATH_PROTOCOL   *Node;
  EFI_DEVICE_PATH_PROTOCOL   *Remainder;

  Status = gBS->HandleProtocol (gImageHandle, &gEfiLoadedImageProtocolGuid, (VOID **)&LoadedImage);
  if (EFI_ERROR (Status)) { return Status; }
  Remainder = DuplicateDevicePath (LoadedImage->FilePath);
  Status = gBS->LocateDevicePath (&gEfiSimpleFileSystemProtocolGuid, &Remainder, VolHandle);
  FreePool (Remainder);
  if (EFI_ERROR (Status)) { return Status; }
  DirPath[0] = L'\0';
  for (Node = LoadedImage->FilePath; !IsDevicePathEnd (Node); Node = NextDevicePathNode (Node)) {
    if ((DevicePathType (Node) == MEDIA_DEVICE_PATH) && (DevicePathSubType (Node) == MEDIA_FILEPATH_DP)) {
      StrnCpyS (DirPath, MOUNT_MAX_PATH, (CONST CHAR16 *)(Node + 1), MOUNT_MAX_PATH - 1);
    }
  }
  // strip the last path component -> directory
  {
    CHAR16  *Last = DirPath;
    CHAR16  *Scan;
    for (Scan = DirPath; *Scan != L'\0'; Scan++) {
      if (*Scan == L'\\') { Last = Scan; }
    }
    *Last = L'\0';   // L"\\sub\\dir" or L"" when the file sat at root
  }
  return EFI_SUCCESS;
}

STATIC
EFI_STATUS
MountBuildDriverDevicePath (
  IN  CONST CHAR16            *DriverFile,
  OUT EFI_DEVICE_PATH_PROTOCOL **DevicePath
  )
{
  EFI_STATUS  Status;
  EFI_HANDLE  VolHandle;
  CHAR16      Dir[MOUNT_MAX_PATH];
  CHAR16      Full[MOUNT_MAX_PATH];

  Status = MountGetSelfDir (&VolHandle, Dir);
  if (EFI_ERROR (Status)) { return Status; }
  if (Dir[0] == L'\0') {
    StrnCpyS (Full, MOUNT_MAX_PATH, DriverFile, MOUNT_MAX_PATH - 1);      // L"drivers\\ntfs.efi"
  } else {
    UnicodeSPrint (Full, sizeof (Full), L"%s\\%s", Dir, DriverFile);
  }
  *DevicePath = FileDevicePath (VolHandle, Full);
  return (*DevicePath != NULL) ? EFI_SUCCESS : EFI_OUT_OF_RESOURCES;
}

  IN CONST CHAR16  *DriverFile
  )
{
  EFI_STATUS                 Status;
  EFI_HANDLE                 *Handles;
  UINTN                      Count;
  UINTN                      Index;
  BOOLEAN                    Found = FALSE;

  Status = gBS->LocateHandleBuffer (ByProtocol, &gEfiLoadedImageProtocolGuid, NULL, &Count, &Handles);
  if (EFI_ERROR (Status)) { return FALSE; }
  for (Index = 0; Index < Count && !Found; Index++) {
    EFI_LOADED_IMAGE_PROTOCOL *Li;
    CHAR16                    *Text;
    if (!EFI_ERROR (gBS->HandleProtocol (Handles[Index], &gEfiLoadedImageProtocolGuid, (VOID **)&Li))) {
      Text = ConvertDevicePathToText (Li->FilePath, FALSE, FALSE);
      if (Text != NULL) {
        // suffix compare on the file-path part (exact case: we built it)
        if (StrStr (Text, DriverFile) != NULL
            && (StrLen (Text) >= StrLen (DriverFile))
            && (StrCmp (Text + StrLen (Text) - StrLen (DriverFile), DriverFile) == 0)) {
          Found = TRUE;
        }
        FreePool (Text);
      }
    }
  }
  FreePool (Handles);
  return Found;
}

MountRunFormat (

  )

  MapSnapshotFsHandles (&OldFs, &OldCount);

  if (MountDriverLoaded (Entry->DriverFile)) {
    Print (L"MOUNT: %s driver already loaded\n", Entry->Name);
  } else {
    Status = MountBuildDriverDevicePath (Entry->DriverFile, &Dp);
    if (EFI_ERROR (Status)) {
      Print (L"MOUNT: error - cannot locate self directory (%r)\n", Status);
      return STATUS_DRIVER_MISSING;
    }
    Status = gBS->LoadImage (FALSE, gImageHandle, Dp, NULL, 0, &Image);
    FreePool (Dp);
    if (Status == EFI_NOT_FOUND || Status == EFI_LOAD_ERROR || Status == EFI_INVALID_PARAMETER) {
      Print (L"MOUNT: error - %s not found (get it from efi.akeo.ie)\n", Entry->DriverFile);
      return STATUS_DRIVER_MISSING;
    }
    if (Status == EFI_SECURITY_VIOLATION) {
      Print (L"MOUNT: error - driver blocked by Secure Boot\n");
      return STATUS_SECURE_BOOT;
    }
    if (EFI_ERROR (Status)) {
      Print (L"MOUNT: error - LoadImage %s failed (%r)\n", Entry->DriverFile, Status);
      return STATUS_DRIVER_MISSING;
    }
    Status = gBS->StartImage (Image, NULL, NULL);
    if (EFI_ERROR (Status)) {
      Print (L"MOUNT: error - StartImage failed (%r)\n", Status);
      return STATUS_DRIVER_MISSING;
    }
    Print (L"MOUNT: driver %s loaded\n", Entry->DriverFile);
    DEBUG ((DEBUG_INFO, "MOUNT: driver %a loaded\n", "<efi>"));   // keep serial ASCII; full path is CHAR16
  }

  MapConnectAllControllers ();
  MapRefreshShell ();
  MapPrintNewVolumes (OldFs, OldCount);
  FreePool (OldFs);
  return EFI_SUCCESS;
}

// Sniff the image: ISO9660 PVD "CD001" at LBA16+1; UDF bridge "BEA01"/
// "NSR02"/"NSR03" descriptors at LBA16..18. Advisory only (spec section 8).
STATIC
VOID
LoopSniff (
  IN EFI_FILE_PROTOCOL  *File,
  OUT BOOLEAN           *Iso9660,
  OUT BOOLEAN           *Udf
  )
{
  UINT8  Buf[6 * LOOP_BLOCK_SIZE];
  UINTN  Size = sizeof (Buf);
  *Iso9660 = FALSE;
  *Udf = FALSE;
  if (EFI_ERROR (File->SetPosition (File, 16 * LOOP_BLOCK_SIZE))
      || EFI_ERROR (File->Read (File, &Size, Buf)) || (Size != sizeof (Buf))) {
    File->SetPosition (File, 0);
    return;
  }
  File->SetPosition (File, 0);
  if (CompareMem (Buf + 1, "CD001", 5) == 0) { *Iso9660 = TRUE; }
  if ((CompareMem (Buf + 2048 + 1, "BEA01", 5) == 0)
      || (CompareMem (Buf + 2 * 2048 + 1, "NSR02", 5) == 0)
      || (CompareMem (Buf + 2 * 2048 + 1, "NSR03", 5) == 0)
      || (CompareMem (Buf + 3 * 2048 + 1, "NSR02", 5) == 0)
      || (CompareMem (Buf + 3 * 2048 + 1, "NSR03", 5) == 0)) {
    *Udf = TRUE;
  }
}

STATIC
EFI_STATUS
LoopCreate (
  IN CONST CHAR16    *IsoPath,
  OUT LOOP_DISK      **DiskOut
  )
{
  EFI_STATUS                Status;
  LOOP_DISK                 *Disk;
  SHELL_FILE_HANDLE         File;
  EFI_FILE_INFO             *Info;
  UINTN                     InfoSize;
  EFI_DEVICE_PATH_PROTOCOL  *FileDp;
  LOOP_VENDOR_MEDIA_NODE    VendorNode;
  BOOLEAN                   Iso9660;
  BOOLEAN                   Udf;
  UINT64                    FileSize;

  Status = ShellOpenFileByName (IsoPath, &File, EFI_FILE_MODE_READ, 0);
  if (EFI_ERROR (Status)) {
    Print (L"MOUNT: error - cannot open %s (%r)\n", IsoPath, Status);
    return STATUS_ISO_ERROR;
  }
  InfoSize = 0;
  ((EFI_FILE_PROTOCOL *)File)->GetInfo ((EFI_FILE_PROTOCOL *)File, &gEfiFileInfoGuid, &InfoSize, NULL);
  Info = AllocatePool (InfoSize);
  if ((Info == NULL)
      || EFI_ERROR (((EFI_FILE_PROTOCOL *)File)->GetInfo ((EFI_FILE_PROTOCOL *)File, &gEfiFileInfoGuid, &InfoSize, Info))) {
    Print (L"MOUNT: error - cannot stat %s\n", IsoPath);
    return STATUS_ISO_ERROR;
  }
  FileSize = Info->FileSize;
  FreePool (Info);
  if (FileSize < LOOP_MIN_SIZE) {
    Print (L"MOUNT: error - file too small, not a valid ISO\n");
    ShellCloseFile (&File);
    return STATUS_ISO_ERROR;
  }
  if ((FileSize % LOOP_BLOCK_SIZE) != 0) {
    Print (L"MOUNT: warn - size not multiple of 2048, tail ignored\n");
  }

  LoopSniff ((EFI_FILE_PROTOCOL *)File, &Iso9660, &Udf);
  if (Iso9660 && !Udf && !MountDriverLoadedByFile (L"drivers\\iso9660_x64.efi")) {
    Print (L"MOUNT: warn - ISO9660 detected but drivers\\iso9660_x64.efi missing\n");
  }
  DEBUG ((DEBUG_INFO, "MOUNT: sniff iso9660=%d udf=%d\n", Iso9660, Udf));

  Disk = AllocateZeroPool (sizeof (*Disk));
  if (Disk == NULL) { ShellCloseFile (&File); return EFI_OUT_OF_RESOURCES; }
  Disk->BackingFile = (EFI_FILE_PROTOCOL *)File;
  Disk->LastBlock   = FileSize / LOOP_BLOCK_SIZE - 1;
  Disk->Seq         = ++mLoopSeq;

  Disk->Media.MediaId          = LOOP_MEDIA_ID;
  Disk->Media.RemovableMedia   = TRUE;
  Disk->Media.MediaPresent     = TRUE;
  Disk->Media.LogicalPartition = FALSE;
  Disk->Media.ReadOnly         = TRUE;
  Disk->Media.WriteCaching     = FALSE;
  Disk->Media.BlockSize        = LOOP_BLOCK_SIZE;
  Disk->Media.IoAlign          = 0;
  Disk->Media.LastBlock        = Disk->LastBlock;
  Disk->MediaPtr = &Disk->Media;

  Disk->BlockIo.Revision  = EFI_BLOCK_IO_PROTOCOL_REVISION;
  Disk->BlockIo.Media     = &Disk->Media;
  Disk->BlockIo.Reset     = LoopReset;
  Disk->BlockIo.ReadBlocks  = LoopReadBlocks;
  Disk->BlockIo.WriteBlocks = LoopWriteBlocks;
  Disk->BlockIo.FlushBlocks = LoopFlushBlocks;

  // Device path: the ISO file's own device path + a unique vendor-media node
  {
    EFI_HANDLE  VolHandle;
    EFI_DEVICE_PATH_PROTOCOL  *Remainder;
    EFI_LOADED_IMAGE_PROTOCOL *Li;
    CHAR16      Dir[MOUNT_MAX_PATH];
    CHAR16      VolRootDp[1];   // unused
    // resolve the volume handle of the ISO by opening its parent volume:
    // reuse Shell: GetDevicePathFromMap is overkill; simplest correct way:
    // build from the shell file path: split "fs1:\dir\win.iso" is NOT done
    // here -- ShellOpenFileByName already resolved it. Ask the Shell for
    // the device path of the file's map prefix instead:
    //   gEfiShellProtocol->GetDevicePathFromMap(L"fs1:") ...
    // Implemented below via MountIsoFileDevicePath().
    FileDp = MountIsoFileDevicePath (IsoPath);
    if (FileDp == NULL) {
      Print (L"MOUNT: error - cannot build device path for %s\n", IsoPath);
      FreePool (Disk);
      ShellCloseFile (&File);
      return STATUS_ISO_ERROR;
    }
  }
  VendorNode.Header.Type    = MEDIA_DEVICE_PATH;
  VendorNode.Header.SubType = MEDIA_VENDOR_DP;   // 0x03
  SetDevicePathNodeLength (&VendorNode.Header, sizeof (VendorNode));
  VendorNode.Guid.Data1 = 0x5C6D7E8F;
  VendorNode.Guid.Data2 = 0x1111;
  VendorNode.Guid.Data3 = 0x4001;
  VendorNode.Guid.Data4[0] = 0x80;
  VendorNode.Guid.Data4[1] = 0x01;
  VendorNode.Guid.Data4[7] = (UINT8)Disk->Seq;
  Disk->DevicePath = AppendDevicePathNode (FileDp, &VendorNode.Header);
  FreePool (FileDp);

  Status = gBS->InstallMultipleProtocolInterfaces (
                  &Disk->Handle,
                  &gEfiDevicePathProtocolGuid, Disk->DevicePath,
                  &gEfiBlockIoProtocolGuid,    &Disk->BlockIo,
                  NULL
                  );
  if (EFI_ERROR (Status)) {
    Print (L"MOUNT: error - InstallProtocolInterfaces failed (%r)\n", Status);
    FreePool (Disk);
    ShellCloseFile (&File);
    return Status;
  }
  *DiskOut = Disk;
  return EFI_SUCCESS;
}

EFI_STATUS
MountRunIso (
  IN CONST CHAR16  *IsoPath
  )
{

  LOOP_DISK   *Disk;
  EFI_HANDLE  *OldFs;
